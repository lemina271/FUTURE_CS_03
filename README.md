# Task 3 - API Security Risk Analysis

## Objective
This project focuses on analyzing public APIs to identify common API security risks and provide remediation recommendations.

## API Tested
- JSONPlaceholder API
https://jsonplaceholder.typicode.com

## Tools Used
- Postman
- Browser DevTools

## Methodology
- Tested API endpoints
- Inspected responses and headers
- Identified security risks
- Classified severity levels
- Documented remediation steps

## Key Findings
| Finding                  | Risk Level |
| ------------------------ | ---------- |
| Open API Endpoint        | High       |
| Unrestricted Data Access | Medium     |
| Excessive Data Exposure  | High       |
| No Rate Limiting         | Medium     |
| Missing Security Headers | Medium     |
| No Authentication        | High       |
